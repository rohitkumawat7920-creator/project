# Multi-Lab Project Repository

This repository contains lab projects across three domains:
- **DSA (Data Structures & Algorithms)**: ATM Management System (C implementation using Arrays, Searching, and Sorting)
- **OPPs (Object Oriented Programming)**: Banking Management System (C++ implementation featuring Encapsulation, Inheritance, Polymorphism, and Abstraction)
- **WebDev (Web Development)**: Parking Management System (Pure HTML5, CSS3, and Vanilla JavaScript with 4 modular sections)
