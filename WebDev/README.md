# Simple Parking Management System (WebDev Lab)

## 📌 Project Overview
A beginner-friendly, clean **Parking Management System** created for a college web development assignment using only pure **HTML5**, **CSS3**, and vanilla **JavaScript** (no frameworks, no external libraries, no local storage).

---

## 🧩 4 Core Modules
1. **Module 1: Parking Slots Status Dashboard**
   - Displays Total Slots (10), Currently Parked Cars, and Available Slots dynamically.
   - Shows user-friendly success and error alert banners.
2. **Module 2: Park a Car (Vehicle Entry)**
   - Form accepting Car Number and Owner Name.
   - Validates input, prevents duplicate cars, and blocks entry when parking is full.
   - Automatically records entry timestamp.
3. **Module 3: Remove a Car (Vehicle Exit)**
   - Form to remove a car by its registration number.
   - Searches the array, removes the vehicle, and frees up a parking slot.
4. **Module 4: Currently Parked Cars List**
   - Interactive HTML table showing Slot #, Car Number, Owner Name, and Entry Time.
   - Re-renders instantly on any entry or exit.

---

## 🛠️ Code Structure
- **`index.html`**: Structured semantic markup for all 4 modules.
- **`style.css`**: Simple, modern styling with card containers and status boxes.
- **`script.js`**: Elementary JavaScript utilizing variables, arrays, basic loops, and DOM manipulation (`document.getElementById`).

---

## 🚀 How to Run
Simply open **`index.html`** in any web browser (Chrome, Edge, Firefox):
- Double click `index.html` in your file explorer, OR
- Right-click `index.html` and choose **Open with > Google Chrome**.
